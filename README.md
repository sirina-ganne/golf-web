# projects

This repository contains two related golf projects:

## `golf-web` (root)

3D golf web experience built with Vite, TypeScript, and Babylon.js.

```bash
npm install
npm run dev
```

## `open-tee/`

Open Tee — an OpenTable-style tee-time search MVP built in Codex (React + Vite).

```bash
cd open-tee
npm install
npm run dev
```
